Build: python build.py
Requires Python 3.9+, pdfLaTeX and the standard packages named in main.tex,
including TikZ. The bibliography is sections/references.tex; no BibTeX run is
required. All .tex inputs are under sections/. Both figures are native TikZ.
Two clean pdfLaTeX passes produced the shipped 25-page PDF.
For exact instance verification, read supplemental/README.md.
