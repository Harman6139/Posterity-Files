# Manuscript II — arithmetic carriers and the all-local obstruction

This release contains the revised complete paper and a separate proof supplement establishing a robust exponential lower bound for every strictly descending extreme-ray adjacent-vertex rule, together with a short global rational separator.

## Read

- `manuscript/MASTER_THEOREM.pdf`: complete revised manuscript, generated by the builder and supplied in the conversation archive.
- `manuscript/ALL_LOCAL_THEOREM.pdf`: new proof supplement, likewise generated and supplied.
- `COMPLETE_PROOFS.md` and `ALL_LOCAL_PROOF.md`: generated full text of the corresponding proofs.
- `STATUS_PROVED_NOT_PROVED.md`: exact achieved scope and remaining publication gates.
- `PRIORITY_AND_SCOPE_ADDENDUM.md`: attribution and limitations.

The complete editable sources and test programs are committed. Generated PDFs and expanded JSON/Markdown are in the downloadable archive; this is not a claim that every derived file is separately committed.

## Rebuild

From this directory:

```sh
python code/build_release.py
python code/build_release.py --pdf --markdown
```

The first command uses only Python's standard library and regenerates and verifies the certificates. PDF and Markdown generation additionally require `pdflatex` with the packages declared in the source, and `pandoc`.

The standalone archive includes copies of the inherited manuscript sections. In the repository, the builder instead reads those unchanged sections from `research/pro_m2_grand_20261115/release/manuscript`. The prior branch and its source files were not overwritten. The complete expanded `MASTER_THEOREM_standalone.tex` is generated as well.

The new theorem is in `manuscript/07_all_local.tex`; the facet relaxation and scalar-ray-correction corollaries are in `08_facet_relaxation.tex`; updated provenance is in `09_provenance.tex`. The original `06_provenance.tex` is retained only as inherited source, not included in the revised paper.

The archive's `inherited_verification/` contains the previous release's code, exact certificates, and unchanged audit files. Those historical status files describe the earlier release; the root status file describes this continuation.

The programs verify exact identities and compressed certificates. They do not simulate exponentially many pivots, implement arbitrary real-algebraic elimination, or formally verify the universal proofs.
