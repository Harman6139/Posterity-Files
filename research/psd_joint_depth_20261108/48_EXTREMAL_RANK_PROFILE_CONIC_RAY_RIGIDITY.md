# Milestone 48 — extremal dense PSD rank-profile exponent forces unique rank-one primal cone flags

**2026-11-08. PROVED as a rigidity corollary of the all-degree dense endpoint theorem (checkpoint 45).** Valid for arbitrary dense kernels, target rank r>=1, and any canonical minimal exposing rank profile with d>=3. This is an intrinsic characterization of a necessary structural feature of endpoint-attaining instances, not a full description of every lower-exponent stratum.

## Theorem

Fix a uniquely solvable PSD inverse problem with minimal facial-reduction degree d>=3 and canonical maximal-rank exposed dimensions
    (s1,...,sd),  s_j>=1, sum s_j=nu.
Let beta(s) be the *sharp attainable universal upper endpoint* in checkpoint 45:
    beta(s)= 2^(s_d-1) P_(d-1) / (sum_(ell=1)^d P_ell),
    P1=1, P_ell=product_(j=2)^ell (2^(s_j)-1).
Assume the actual sharp full-state exponent **attains equality**, alpha=beta(s).

For every exposed layer R_j with j>=2, consider the following recursive procedure: start with R_remaining=R_j; let W_(j-2) be the face before the preceding exposing step and K_(j-2)=K∩S(W_(j-2)); set Q_R={P_(R_remaining⊕R_(j-1))H P_(R_remaining⊕R_(j-1)): H∈K_(j-2)}. The homogeneous cone
    C_R=Q_R∩S_+(R_remaining⊕R_(j-1))
must be a **single positive rank-one ray**:
    C_R={t vv^T:t>=0}
for a unique line span(v)⊂R_remaining.

Consequently the recursive selection of positive kernel compressions canonically determines **exactly s_j one-dimensional orthogonal subspaces** in every exposed layer j>=2; no projection cone can have a rank-two PSD element or two linearly independent PSD rays. This yields a canonical orthogonal rank-one *primal conic flag* within every nonterminal facial block, uniquely determined by the original dense measurement kernel and the canonical exposing faces (up to signs on individual lines).

## Proof

The conic flag lemma in checkpoint 45 proves, without any additional assumptions, that every projected cone C_R is nonzero and that choosing a PSD element of rank r_R>=1 exposes an r_R-dimensional current subspace, requiring at most s_j-r_R+1 strictly positive stages to finish the decomposition of layer j. Thus **if any projected PSD cone contains an element of rank >=2**, one may start the construction at that point and obtain a conic flag with k_j<=s_j-1 in this layer, while k_i<=s_i in all other layers. Applying the coefficient-rescaling construction in checkpoint 45 to these modes yields
    alpha <= beta(k_2,...,k_d)
where the same rational expression beta is evaluated with numbers k_j in place of s_j.

For d>=3, the explicit formula
    beta(k)=1/[2(1+2^(-k_d) S(k_2,...,k_(d-1)))],
    S= sum_(ell=1)^(d-2) [ product_(j=ell+1)^(d-1)(2^(k_j)-1) ]^(-1)
has S>0 and is **strictly increasing in each positive integer k_j**, j>=2. Thus if k_j<s_j for any j, the constructed curve forces
    alpha <= beta(k) < beta(s),
contradicting endpoint equality.

Therefore no C_R can contain any PSD matrix of rank>=2. Since C_R is a nonzero convex cone of PSD matrices, any two nonproportional nonzero members would have rank-two-or-more sum (for PSD matrices ker(A+B)=ker A∩ker B), contradiction. Hence C_R is exactly a ray generated by one positive rank-one vv^T.

At each recursive stage the support line span(v) is unique; its removal leaves a canonical orthogonal complement. The same argument applies inductively to every subsequent projected cone and every facial layer, yielding s_j canonical one-dimensional subspaces as claimed. QED.

## A quantitative strict near-endpoint condition

Let
\[
\beta_{\rm collapse}(s)=
\max_{\substack{1\le k_j\le s_j,\ j=2,...,d\\
               (k_2,...,k_d)\ne(s_2,...,s_d)}}
\beta(k_2,...,k_d).
\]
If some nonterminal exposed layer has s_j>=2, the maximization set is nonempty and strict monotonicity gives beta_collapse(s)<beta(s). Therefore any dense instance with
    alpha > beta_collapse(s)
already has the same rank-one-ray rigidity in every projected cone, even if alpha<beta(s).

This is an explicit **finite rational gap** between an extremal geometric stratum and every rank-collapsed conic-flag mechanism. It does not assert the absence of other full-rank-one-flag exponent values inside that interval.

## Scope

This result strengthens the statement "the sparse layered graph attains the upper bound": it proves that any DENSE endpoint-attaining instance must have the same *one-dimensional sequence of positive projected kernel directions* at every exposing stage, although its full coefficient matrices may remain dense and need not have the sparse graph support pattern. It is a robust necessary structural invariant, not an asserted equivalence of exact feasible sets, matrix sparsification, or all-degree subendpoint spectra.

The homogeneous Gordan–Stiemke alternative and PSD cone rank additivity are standard; the equality-case implication follows rigorously from the new universal endpoint bound. Bibliographic priority is not independently established.
