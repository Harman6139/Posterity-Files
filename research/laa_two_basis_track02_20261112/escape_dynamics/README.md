# Escape-controlled projection dynamics

Companion to `26_ESCAPE_CONTROLLED_PROJECTION_DYNAMICS.md`, dated 2026-11-13.

## Reproduce

Requires Python 3.10+ and NumPy. Run:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python test_escape_dynamics.py --iterations 40000 --output DYNAMICS_RESULTS.json
```

The script implements orthogonal PSD and affine projections and the exact accelerated recurrence stated in the proof. It tests fixed-comparator energy inequalities, records tail log-log slopes, and checks scalar nonattainment examples. It does not call an SDP solver or access the network.

The supplied results were generated by this command. The six matrix cases use the two rational endpoint families at matrix orders two and three. `fast` and `slow` name STATIC TRACE ESCAPE, not algorithmic speed. Eight scalar cases test `(1+x)^(-p)` on `x>=0`. The affine projector uses NumPy's pseudoinverse; cone projection uses eigenvalue clipping.

Floating-point results are diagnostics, not proofs. Slope fits can be affected by long transients; the asymptotic results are derived in the manuscript, not inferred from these tests. This is not a reliable finite-time feasibility classifier or a bit-complexity claim.

The main mathematical result is that a minimum objective-radius law `rho(s)=Theta(s^(-beta))` determines both objective decay and iterate growth. Ordinary projected gradient has powers `1/(2beta+1)` and `beta/(2beta+1)`; the specified accelerated method doubles both. For weakly infeasible SDPs the trace-escape exponent `a` from manuscript 12 gives residual powers `1/[2(a+1)]` and `1/(a+1)`, respectively.
