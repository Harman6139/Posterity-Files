# Tame cosmic-convergence proof packet

The three Markdown manuscripts at the top of this bundle are the mathematical proof and its scope guide. `test_tame_cosmic.py` supplies exact finite identities and numerical illustrations, not a proof of the universal theorem.

Run `python test_tame_cosmic.py` with Python 3 and SymPy. The script writes `TAME_COSMIC_RESULTS.json`. It needs no network or optimization solver.

The main theorem has no dependency on the earlier two-basis SDP compiler, dimension envelopes, or counting arguments. It assumes finite dimension, a closed convex domain, nonexpansiveness, no fixed point, and o-minimal definability. Semialgebraicity gives the exact rational power law. The unrestricted cosmic-convergence conjecture is known false; the tame theorem is a positive result with an essential extra hypothesis.

The per-file SHA256 manifest is supplied to preserve this packet exactly. No external refereeing, formal proof-assistant check, exhaustive priority determination, or publication acceptance is claimed.
