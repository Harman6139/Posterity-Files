# Homepage redesign implementation summary

Use this as the implementation checklist for the final homepage redesign.

## Site direction
Make the site feel authored, editorial, specific and human-made. Remove the current generic dark AI-portfolio look.

## Fonts
- Display: Space Grotesk, Satoshi or General Sans
- Body: Inter
- Tech labels: Inter
- Hero: 54-62px
- Card titles: 28-34px
- Body: 15-17px
- Tech boxes: 12-13px

## Palette
- Background: #07111F
- Panels: #0E1A2B
- Primary text: #F4F6F8
- Secondary text: #A8B3C2
- Blue accent: #4A7CFF
- Red accent: #C84B5A
- Border: rgba(140,170,210,0.16)

## Remove
- top-left logo
- integration-draft banner
- project numbers
- long workflow text on homepage cards
- placeholder workflow diagrams
- AI-style slogans
- em dashes

Make Harman Singh larger and bolder in the header.
