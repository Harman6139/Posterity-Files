Refine the **Citadel FI&M Central Bank Challenge** page so it presents the policy-path engine as a sharp, visually clean quantitative project.

This page already has strong slide assets. The goal is not to reinvent the work, but to present it more elegantly and consistently with the final homepage design system.

## Project naming
- **Primary title:** `Policy-Path Scenario Engine`
- **Secondary line (small):** `Citadel FI&M Central Bank Challenge`

## Design direction
Use a **white editorial background** with restrained navy accents.

Visual goals:
- crisp
- slide-led
- serious
- spacious
- polished

Avoid:
- dark heavy backgrounds
- generic AI-style headings
- decorative filler copy
- repeated process captions that restate the slides
